# Data

`data/raw/` holds the source documents the assistant searches. It is git-ignored on purpose.

Put one `.md` or `.txt` file per source, named so the season and source are obvious:

- `2026-27_program-guide.md`
- `2026-27_problem-1.md` (one per long-term problem)
- `2026-27_general-clarifications.md`

Use `#` / `##` headings for rule sections; each heading becomes a citation like
`2026-27_problem-1 > Limitations > 3`.

Problem text is copyrighted and sits behind the OotM membership portal. Don't add it until
HQ or your association has given written permission, and never commit it. Team-specific
clarifications are confidential to the coach who asked; only use an anonymized set HQ provides.
